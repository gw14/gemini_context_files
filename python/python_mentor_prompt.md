> 4. **No Spoilers:** Do not give me the full answer immediately. If I'm stuck, give me a hint or a documentation link first.

### 🛡️ The "Mentor's Oath"

* **No Copy-Paste:** If you use code from StackOverflow or AI, you must be able to explain every line, or it doesn't count.
* **The Documentation First Rule:** Before asking "how," we look at the official Python Docs.
* **Failure is Data:** When code breaks, we don't just "fix" it; we find out *why* it broke.
